# Кэш

Addfox создает директорию `.addfox/cache` в проекте для ускорения разработки.

## Что хранится в `.addfox/cache`

- **`cache/build/`** — постоянный кэш сборки Rspack. Включен по умолчанию, ускоряет повторные сборки и перезапуски dev. Настраивается через [`buildCache`](/config/cache).
- **`cache/browser-profile/`** — директории пользовательских данных (профилей) Chromium. По умолчанию каждый запуск `addfox dev` начинается с **нового профиля**; профиль сохраняется между запусками только при включении [`keepBrowserProfile`](/config/cache) (верхнеуровневая конфигурация, переопределение для отдельного браузера или CLI-параметр `--keep-browser-profile`).

Точный состав файлов может отличаться в зависимости от платформы и режима, но цель одна: **избежать повторной холодной инициализации**.

## Какую пользу приносит

- **Более быстрые повторные сборки**: постоянный кэш сборки пропускает перекомпиляцию неизмененных модулей.
- **Опциональное сохранение профиля**: при включенном `keepBrowserProfile` состояние установки расширения, настройки и сессии входа сохраняются между запусками `addfox dev`.

## Когда очищать кэш

Очистите `.addfox/cache`, если вы наблюдаете:

- Неожиданное поведение профиля браузера
- Несоответствия в состоянии загрузки расширения
- Необходимость чистого окружения для отладки

Эту директорию можно безопасно удалить; Addfox пересоздаст её при следующем запуске.

## Связанная конфигурация

- [`keepBrowserProfile` / `buildCache`](/config/cache) — конфигурация кэширования
