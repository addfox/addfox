# keepBrowserProfile

`keepBrowserProfile` используется для управления сохранением пользовательских данных браузера (профиля) при разработке.

## Обзор

- **Тип**: `boolean`
- **Значение по умолчанию**: `false`
- **Обязательный**: Нет

## Использование

```ts
// addfox.config.ts
import { defineConfig } from "addfox";

export default defineConfig({
  keepBrowserProfile: true,  // Сохранять профиль браузера между запусками
});
```

## Влияние

При включении:
- Пользовательские данные браузера сохраняются в директории `.addfox/cache/browser-profile/<name>-user-data`
- При следующем запуске `addfox dev` эти данные переиспользуются
- Состояние входа, настройки расширения и т.д. сохраняются

Можно также переопределить для отдельного браузера:

```ts
export default defineConfig({
  browser: {
    chrome: { keepBrowserProfile: true },
  },
});
```

## Приоритет

Разрешается в следующем порядке (от высшего к низшему):

1. CLI `--keep-browser-profile` / `--no-keep-browser-profile`
2. `browser.<name>.keepBrowserProfile` (переопределение для отдельного браузера)
3. Верхнеуровневый `keepBrowserProfile`
4. Устаревший `cache` (CLI `-c/--cache`, `--no-cache` или конфигурация `cache`)
5. Значение по умолчанию `false`

:::warning
Поле конфигурации `cache` и CLI-параметры `-c/--cache`, `--no-cache` — устаревшие (deprecated) псевдонимы; они по-прежнему работают, но выводят предупреждение об устаревании в терминале. Мигрируйте на `keepBrowserProfile` и `--keep-browser-profile` / `--no-keep-browser-profile`.
:::

## Примечания

- Влияет только на режим разработки (`addfox dev`)
- Не влияет на Firefox; профиль Firefox управляется `web-ext`
- При возникновении странных проблем попробуйте очистить директорию `.addfox/cache/`

# buildCache

`buildCache` управляет **постоянным кэшем сборки Rspack**, ускоряя повторные сборки.

## Обзор

- **Тип**: `boolean | { cacheDirectory?: string }`
- **Значение по умолчанию**: `true`
- Файлы кэша сохраняются в `<outputRoot>/cache/build/`

## Использование

```ts
export default defineConfig({
  // Отключить кэш сборки
  buildCache: false,
});
```

```ts
export default defineConfig({
  // Пользовательская директория кэша
  buildCache: { cacheDirectory: "./node_modules/.cache/addfox-build" },
});
```

Для более глубокой настройки rsbuild/rspack используйте существующее поле конфигурации [`rsbuild`](/config/rsbuild) (объект с глубоким слиянием или функция).
