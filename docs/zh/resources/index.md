# 资源

Addfox 以一系列包的形式发布。大多数用户只需要主包 `addfox` 的 CLI，但以下包也可以独立使用，集成到你自己的工具或工作流中。

| 包 | 用途 |
|---------|---------|
| [`@addfox/launcher`](/resources/launcher) | 启动 Chromium/Gecko 浏览器并加载扩展，支持文件监听与远程调试。 |
| [`@addfox/cli`](/resources/cli) | `addfox` 的命令行解析器、构建流水线和 Rsbuild 运行器。可编程使用以构建自定义扩展工具。 |
| [`create-addfox-app`](/resources/create-addfox-app) | 交互式脚手架，用于创建新的 Addfox 扩展项目。 |

点击上方包名查看安装与使用说明。
