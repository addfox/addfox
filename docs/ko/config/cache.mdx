# keepBrowserProfile

`keepBrowserProfile`은 개발 시 브라우저 사용자 데이터(profile)를 유지할지 여부를 제어합니다.

## 개요

- **타입**: `boolean`
- **기본값**: `false`
- **필수 여부**: 아니오

## 사용법

```ts
// addfox.config.ts
import { defineConfig } from "addfox";

export default defineConfig({
  keepBrowserProfile: true,  // 실행 사이에 브라우저 profile 유지
});
```

## 역할

활성화하면:
- 개발 시 브라우저 사용자 데이터가 `.addfox/cache/browser-profile/<name>-user-data` 디렉토리에 저장됩니다
- 다음에 `addfox dev`를 시작할 때 이 데이터를 재사용합니다
- 로그인 상태, 확장 설정 등이 유지됩니다

브라우저별로 최상위 구성을 재정의할 수도 있습니다:

```ts
export default defineConfig({
  browser: {
    chrome: { keepBrowserProfile: true },
  },
});
```

## 우선순위

다음 순서로 해석됩니다(높은 순):

1. CLI `--keep-browser-profile` / `--no-keep-browser-profile`
2. `browser.<name>.keepBrowserProfile` (브라우저별 재정의)
3. 최상위 `keepBrowserProfile`
4. Deprecated `cache` (CLI `-c/--cache`, `--no-cache` 또는 구성 `cache`)
5. 기본값 `false`

구성 필드 `cache`와 CLI 파라미터 `-c/--cache`, `--no-cache`는 deprecated 별칭이며, 여전히 동작하지만 터미널에 deprecated 경고를 출력합니다. `keepBrowserProfile`과 `--keep-browser-profile` / `--no-keep-browser-profile`로 마이그레이션하세요.
:::

## 주의사항

- 개발 모드(`addfox dev`)에만 영향을 줍니다
- Firefox에는 영향을 주지 않습니다. Firefox profile은 `web-ext`가 관리합니다
- 이상한 문제가 발생하면 `.addfox/cache/` 디렉토리를 삭제해 보세요

# buildCache

`buildCache`는 **Rspack 영구 빌드 캐시**를 제어하여 반복 빌드를 가속합니다.

## 개요

- **타입**: `boolean | { cacheDirectory?: string }`
- **기본값**: `true`
- 캐시 파일은 `<outputRoot>/cache/build/`에 저장됩니다

## 사용법

```ts
export default defineConfig({
  // 빌드 캐시 비활성화
  buildCache: false,
});
```

```ts
export default defineConfig({
  // 사용자 정의 캐시 디렉토리
  buildCache: { cacheDirectory: "./node_modules/.cache/addfox-build" },
});
```

더 깊은 rsbuild/rspack 사용자 정의가 필요하면 기존 [`rsbuild`](/config/rsbuild) 구성 필드(객체 깊은 병합 또는 함수 형태)를 사용하세요.
