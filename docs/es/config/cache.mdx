# keepBrowserProfile

`keepBrowserProfile` se utiliza para controlar si se conservan los datos de usuario del navegador (perfil) durante el desarrollo.

## Resumen

- **Tipo**: `boolean`
- **Valor por defecto**: `false`
- **Requerido**: No

## Uso

```ts
// addfox.config.ts
import { defineConfig } from "addfox";

export default defineConfig({
  keepBrowserProfile: true,  // Conservar el perfil del navegador entre ejecuciones
});
```

## Función

Después de habilitarlo:
- Los datos de usuario del navegador durante el desarrollo se guardan en el directorio `.addfox/cache/browser-profile/<name>-user-data`
- Se reutilizan estos datos la próxima vez que se inicie `addfox dev`
- Estado de inicio de sesión, configuraciones de extensión, etc. se conservan

También puedes sobrescribir la configuración de nivel superior por navegador:

```ts
export default defineConfig({
  browser: {
    chrome: { keepBrowserProfile: true },
  },
});
```

## Prioridad

Se resuelve en el siguiente orden (de mayor a menor):

1. CLI `--keep-browser-profile` / `--no-keep-browser-profile`
2. `browser.<name>.keepBrowserProfile` (sobrescritura por navegador)
3. `keepBrowserProfile` de nivel superior
4. `cache` obsoleto (CLI `-c/--cache`, `--no-cache` o configuración `cache`)
5. Valor por defecto `false`

## Parámetros de CLI

Los parámetros de CLI tienen mayor prioridad que la configuración:

Cuando `--keep-browser-profile` y `--no-keep-browser-profile` aparecen simultáneamente, prevalece el último parámetro.

:::warning
El campo de configuración `cache` y los parámetros de CLI `-c/--cache`, `--no-cache` son alias obsoletos (deprecated); siguen funcionando pero muestran una advertencia de deprecación en la terminal. Migra a `keepBrowserProfile` y `--keep-browser-profile` / `--no-keep-browser-profile`.
:::

## Notas

- Solo afecta modo de desarrollo (`addfox dev`)
- No afecta a Firefox; el perfil de Firefox es gestionado por `web-ext`
- Cuando encuentres problemas extraños, intenta limpiar el directorio `.addfox/cache/`

# buildCache

`buildCache` controla la **caché de construcción persistente de Rspack**, que acelera las construcciones repetidas.

## Resumen

- **Tipo**: `boolean | { cacheDirectory?: string }`
- **Valor por defecto**: `true`
- Los archivos de caché se guardan en `<outputRoot>/cache/build/`

## Uso

```ts
export default defineConfig({
  // Deshabilitar la caché de construcción
  buildCache: false,
});
```

```ts
export default defineConfig({
  // Directorio de caché personalizado
  buildCache: { cacheDirectory: "./node_modules/.cache/addfox-build" },
});
```

Para una personalización más profunda de rsbuild/rspack, usa el campo de configuración [`rsbuild`](/config/rsbuild) existente (fusión profunda de objetos o forma de función).
