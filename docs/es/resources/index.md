# Resources

Addfox is published as a collection of packages. While most users only need the main `addfox` CLI, several packages can also be used independently in your own tooling or workflows.

This section documents the standalone packages:

| Package | Purpose |
|---------|---------|
| [`@addfox/launcher`](/resources/launcher) | Launch Chromium/Gecko browsers with extensions loaded, with file watching and remote debugging support. |
| [`@addfox/cli`](/resources/cli) | The `addfox` CLI parser, pipeline, and Rsbuild runner. Use it programmatically to build custom extension tooling. |
| [`create-addfox-app`](/resources/create-addfox-app) | Scaffold a new Addfox extension project interactively. |

Choose a package above to learn how to install and use it.
